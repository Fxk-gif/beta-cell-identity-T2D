# Reviewer 1 (Comments 1-6, 8): code overview

> The seven code directories below correspond to the supplementary validation
> analyses for Reviewer 1's Comments 1-6 and 8. All code runs on publicly
> available data (GEO) in a Python 3 environment, and the results match the
> output files included in each directory.

---

## 1. Directory index

| Directory | Comment | Main script | Result |
|---|---|---|---|
| `comment1_single_cell_pseudoreplication` | #1 single-cell pseudoreplication | `xin_donor_level.py` / `baron_donor_level.py` | donor-level re-run: SLC2A2/IAPP not significant, GCK/PCSK2 up-regulated |
| `comment2_independent_cohorts` | #2 "independent cohorts" wording | `donor_overlap_check.py` | three-layer donor-overlap check: overlap = 0 |
| `comment3_gsea_circularity` | #3 GSEA circularity | `overlap_corrected_gsea.py` | after removing circularity, PDX1/HNF1A enrichment disappears; only beta functional set remains significant |
| `comment4_cell_fraction` | #4 cell fraction / deconvolution | `cell_fraction_analysis.py` | beta-cell fraction does not decrease (increases), prior claim withdrawn |
| `comment5_confounder_adjustment` | #5 confounder adjustment | `confounder_adjustment.py` | discovery cohort loses significance after adjustment; validation cohort remains significant |
| `comment6_overfitting` | #6 diagnostic overfitting | `overfitting_assessment.py` | multivariate model overfits; the single-gene SLC2A2 model is preferable |
| `comment8_trace_level_probes` | #8 trace-level probes / progenitor score | `progenitor_score_bulk.py` | progenitor/disallowed score recomputed at full precision (p = 1.37e-11 / 2.45e-4); trace-level caveat documented |

## 3. Running the analyses

All scripts locate their data directories via environment variables:

```bash
# Workspace root (containing r3_inputs/ geo_data/ sc_data/)
export T2D_DATA=/path/to/workspace
export T2D_SC_DATA=/path/to/workspace/sc_data
export T2D_R3_INPUTS=/path/to/workspace/r3_inputs

# Run each script (Python 3; numpy/pandas/scipy/scikit-learn)
python comment1_single_cell_pseudoreplication/xin_donor_level.py
python comment1_single_cell_pseudoreplication/baron_donor_level.py
python comment2_independent_cohorts/donor_overlap_check.py <GSE76895_series_matrix.txt.gz> <GSE76894_series_matrix.txt.gz>
python comment3_gsea_circularity/overlap_corrected_gsea.py
python comment4_cell_fraction/cell_fraction_analysis.py
python comment5_confounder_adjustment/confounder_adjustment.py
python comment6_overfitting/overfitting_assessment.py
python comment8_trace_level_probes/progenitor_score_bulk.py
```

Each directory includes the corresponding `*_output.txt` (full run output) and a
`README.md` with details for that comment.

## 4. Notes on the supplementary results

1. All supplementary results were generated by the code above and match the
   output files in each directory.
2. Several results are unfavorable to the original manuscript (e.g. Comment 4:
   beta-cell fraction does not decrease; Comment 5: the discovery cohort loses
   significance after adjustment). These are reported in full and discussed in
   the response letter.
3. For Comment 3, the original script for the KLF10 hypothesis-free analysis
   (hTFtarget database) was not archived with the initial submission. KLF10 has
   been re-characterized as a curation-independent, hypothesis-free finding that
   is not treated as independent validation of the PDX1/HNF1A cascade. The code
   for this comment therefore covers only the circularity quantification and
   the de-circularized GSEA (`overlap_corrected_gsea.py`), consistent with the
   response letter and the final manuscript.
