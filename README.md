# Analysis code — "Reduced β-cell identity across separate datasets is associated with reduced expression of the mature β-cell program in type 2 diabetic islets"

This repository contains the complete, reproducible analysis code for the manuscript (Frontiers in Endocrinology, Manuscript ID 2015413). All statistical results reported in the paper and in the point-by-point response to reviewers can be regenerated by running these scripts.

## Data sources

All datasets are publicly available from GEO (GEO is the only source; no additional data were generated):

| Accession | Description | Platform | Donors / Samples |
|---|---|---|---|
| GSE76895 | Human pancreatic islets, partial-pancreatectomy (PPP) cohort | GPL570 (Affymetrix HG-U133 Plus 2.0) | 68 samples (36 T2D, 32 ND; full series also includes IGT/T3cD) |
| GSE76894 | Human pancreatic islets, organ-donor (OD) cohort | GPL570 | 103 samples (19 T2D, 84 ND) |
| GSE81608 | Single-cell RNA-seq (Smart-seq2), Xin et al. | Smart-seq2 | 18 donors (12 ND, 6 T2D) |
| GSE84133 | Single-cell RNA-seq (inDrop), Baron et al. | inDrop | 4 donors (3 ND, 1 T2D) |

The two bulk datasets (GSE76895, GSE76894) originate from the IMIDIA biobank but derive from **distinct, non-overlapping donor groups** (partial-pancreatectomy vs. organ-donor), as stated in the manuscript.

## Script descriptions

### Main bulk analyses

| Script | Purpose |
|---|---|
| `analysis.R` | Defines the β-cell identity score and runs the main bulk differential analysis on GSE76895 (training) |
| `validation.R` | Independent cross-validation of the identity score in GSE76894 |
| `consistency.R` | Cross-dataset concordance of the identity score |

### Single-cell analyses (donor-level)

| Script | Purpose |
|---|---|
| `xin_donor_level.py` | **Donor-level** differential expression in Xin et al. (GSE81608, 18 donors). Aggregates β-cell RPKM per donor, then Wilcoxon rank-sum with BH-FDR correction — replaces the pseudoreplicated cell-level test flagged by Reviewers 1/2 |
| `baron_donor_level.py` | **Donor-level** extraction in Baron et al. (GSE84133). T2D is a single donor (human4), so only directional log2FC is reported (no p-value), per reviewer request |
| `sc_extract.py` / `sc_stats.py` | Single-cell β-cell extraction and statistics (legacy cell-level implementation) |
| `baron_extract.py` | Extracts β-cell profiles from Baron et al. (GSE84133) |

### Gene set enrichment (GSEA)

| Script | Purpose |
|---|---|
| `gsea.py` | Original GSEA (hand-written enrichment score + permutations) |
| `gsea_overlap_corrected.py` | **Overlap-corrected GSEA** — removes genes shared between curated TF target sets and the identity score, addressing the reviewer circularity concern (R1-3). Includes a sanity check reproducing the original ES values |
| `gsea_plot.R` | GSEA enrichment plots |

### Confounder adjustment (R1-5)

| Script | Purpose |
|---|---|
| `confounder_adjustment.py` | Multiple linear regression `identity score ~ group + age + gender + BMI + batch` using sample-level covariates parsed from the GEO series matrices; reports adjusted and unadjusted p-values |

### Diagnostic models and networks

| Script | Purpose |
|---|---|
| `ml_identity_model.py` | β-cell identity diagnostic models (logistic / SVM / random forest) with ROC, calibration, and nomogram |
| `ml_cv_rerun.py` | **Cross-validation + bootstrap AUC confidence intervals + balanced accuracy / MCC** — addresses R1-6/R2-8 (the original `ml_identity_model.py` used only a train/test split) |
| `ml_identity_consistency.py` | Consistency analysis of the identity network |
| `tf_network_figure.py` | Transcription-factor regulatory network (PDX1/HNF1A) |
| `ppi_network_figure.py` | STRING protein–protein interaction network |

### Supplementary analyses

| Script | Purpose |
|---|---|
| `reviewer_supplement_analysis.py` | Exploratory supplementary analyses (single-cell "core score" and progenitor/disallowed score reversal). Note: the single-cell core score here is cell-level (legacy); the manuscript's single-cell conclusions follow the donor-level scripts above |
| `spearman_correlation.py` | **Spearman rank correlation** of per-gene fold changes across cohorts — shows ρ = 0.11 (all 15 genes) falling to −0.10 on excluding SLC2A2, confirming the concordance is driven by a single high-leverage gene |

### Data preprocessing

| Script | Purpose |
|---|---|
| `collapse_genes.py` | Collapses microarray probes to gene symbols |
| `build_r3_inputs.py` | Builds the analysis input files (`r3_inputs/`) |

## Reproduction notes

1. Download the four GEO datasets listed above; place processed matrices in `data/` (or set `T2D_REPO_DATA`).
2. Run `collapse_genes.py` then `build_r3_inputs.py` to prepare the bulk input matrices.
3. Run `analysis.R` for the main bulk analysis, `validation.R` and `consistency.R` for validation and concordance.
4. Run `gsea.py` then `gsea_overlap_corrected.py` for GSEA (the latter reproduces the original ES values before removing shared genes).
5. Run `confounder_adjustment.py` for the confounder-adjusted results.
6. Run `xin_donor_level.py` and `baron_donor_level.py` for the donor-level single-cell reanalysis.
7. Run `ml_cv_rerun.py` for cross-validation and AUC confidence intervals; `spearman_correlation.py` for the rank-based concordance check.

All p-values reported in the overlap-corrected GSEA, confounder adjustment, donor-level single-cell analysis, cross-validation, and Spearman correlation were computed with these scripts and match the values in the manuscript and the response to reviewers.

## Reviewer-response modules

The `reviewer1/`, `reviewer2/`, and `figures/` directories contain the code modules written to address specific reviewer comments during revision. See `README_overview.md` for a directory-by-directory index. Together with the original pipeline above, they reproduce every analysis reported in the manuscript and in the point-by-point responses.

- `reviewer1/` — modules addressing Reviewer 1's comments (pseudoreplication, donor-overlap, GSEA circularity, cell fraction, confounder adjustment, overfitting, progenitor score).
- `reviewer2/` — modules addressing Reviewer 2's comments (sensitivity analyses, glycemia/proxy adjustment, TF/effector split).
- `figures/` — scripts that regenerate the revised figures.
